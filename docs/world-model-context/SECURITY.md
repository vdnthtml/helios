# Evidence, privacy, and source boundaries

This is an architecture requirement document, not an implemented control system or a legal opinion.

Support shared permitted public/licensed intelligence, private personal workspaces, private enterprise workspaces, and explicitly approved contributions. Shared algorithms and schemas do not imply shared private records.

Enforce authorization before evidence reaches retrieval, generation, embeddings, external models, or tool calls. Carry applicable restrictions through relationships, summaries, caches, derived conclusions, exports, and monitoring alerts. Mixed-source derivations require a deliberate permitted-output policy rather than a guess that paraphrasing makes information public.

Retain source licenses, provider boundaries, collection permissions, scoped connector credentials, audit events, protected transport/storage, correction/deletion procedures, and retention rules. Advanced private deployments and customer key management are future options.

Use legitimate public, licensed, or consented acquisition. Public accessibility is not permission for every reuse. Model documented professional behavior and disclosed criteria; do not assert hidden sensitive traits or vulnerabilities. Meeting capture requires appropriate authorization and a defined retention policy.

Retrieved pages, interviews, documents, and tool outputs are untrusted evidence, not instructions. Sending messages, publishing, changing external systems, and other actions need appropriate task authorization. A draft remains a draft until sending is actually verified.

Corrections must distinguish user feedback from verified external factual amendments. Handle retractions and dependent outputs. Applicable deletion obligations can include independently obtained data; do not carry forward the early blanket “public means never removable” idea.

Keep credentials, private unrelated user history, and unrestricted customer exports outside portable handoff bundles. This initial bundle contains the supplied project discussion and derived project documentation only. Review audience before sharing the full transcript externally.
