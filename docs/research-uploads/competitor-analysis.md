# Helios Signal v0.1 — Real-Product Architectures Audit

**Date checked: 14 Nov 2026 (searches run 14 Nov 2026; underlying vendor-page reads cited are mostly Aug–Nov 2026). Researcher: specialist subagent.**\
**Scope:** how real social-listening / community-intelligence products actually architect, price and deliver — from public sources only (vendor pages/docs, engineering blogs, GitHub, third-party roundups that cite vendor pages). No prices invented. Anything not verified on a vendor page or a dated secondary check is marked **UNVERIFIED**.\
**Helios Signal context (from task):** founder-led B2B AI/dev-tool companies; monitor X + HN + GitHub + Bluesky + RSS; rank customer problems / competitor moves / unmet needs; recommend an action; paid pilots then subscriptions. Test bands: founder pilot ₹5,000–15,000/mo (\~$57–170/mo), agency/team pilot ₹20,000–50,000/mo (\~$227–568/mo). Wedge: ranked action recommendations + brief, not alerts-only; dev-community focus; $100–200/mo empty space.

## Method & honesty notes

- Prices below are **monthly, USD, unless stated**; "annual" = per-month price when billed annually. Monthly-billing price is higher where shown.
- Most vendors disclose **features and data-scale claims, not stack internals**. No vendor in this set publishes a full stack (DB, queue, language) on a public engineering blog that this research could verify. Where architecture is "not disclosed", that is stated — it is not a gap in this report, it is the public record. Do not cite a stack for these vendors that is not in the table.
- Several roundups used here are written by competing vendors (ParseStream, Bazzly, SnitchFeed, Updately, Octolens). Their price figures were cross-checked across ≥2 independent sources where possible; where only one (vendor-affiliated) source exists, it is flagged.
- **Reddit cliff — load-bearing for Helios, verified from multiple secondary reports of Reddit's 30 Sep 2026 announcements:** new public Data API requests stop 31 Oct 2026; Reddit RSS ends 13 Nov 2026 (no replacement for non-moderators); unregistered apps start losing access 12 Jan 2027; public Data API closes Mar 2027. Survivors: Reddit Pro (first-party, free beta), licensed enterprise data agreement (Meltwater is an Official Reddit Data Partner, Feb 2026), or a Devvit app (TypeScript only, Python/PRAW not supported). GummySearch is the casualty proof: no commercial licence → stopped new signups 30 Nov 2025, full shutdown/data deletion 1 Dec 2026. **Any Helios Reddit plan built on RSS / public .json / PRAW is dead on arrival after 13 Nov 2026 / Mar 2027. HN (Algolia API, no key) and Bluesky (public AT Protocol AppView) are the only genuinely free, keyless, durable sources in the set.**

**The gap is real and it is exactly where Helios's test bands sit:** $57–170/mo founder pilot undercuts Octolens Pro ($159) at the top end and sits *above* the $29–49 alerts-only tier — which is correct, because Helios sells judgement, not alerts. The $227–568 agency band sits between Octolens Scale ($499) and Brand24 Pro ($399) — defensible only if the agency tier ships multi-client briefs + battlecards, not just more keywords.\
**What nobody sells under $200:** a ranked action recommendation + brief + draft. Octolens/Syften/SnitchFeed score relevance/intent; Brand24/Meltwater/Brandwatch summarise; none of them tells a founder *what to do first on Monday, in what order, with the words to use*. That is the wedge, and it is unoccupied at every price in this audit.

## Ranked: 5 most stealable architectural ideas

1. **Octolens — company-context LLM relevance scoring (High/Med/Low) + API/webhooks/MCP on every plan.** The relevance layer is the product; the data layer being open on the entry tier is the distribution. Copy both, in that order.
2. **SnitchFeed — intent taxonomy as the ranking spine (seeking alternative / competitor complaint / buying intent / pain point / feature request / praise) + MCP+API on entry.** Helios's rank function should be built on these tags, not on sentiment alone.
3. **Harken — one normalised Mention schema → SQLite → local-lexicon sentiment (optional LLM) → TF theme clustering.** The cheapest correct v0.1 data layer; copy it literally, then swap SQLite→Postgres when multi-client arrives.
4. **OpenMagpie — pluggable connectors → BYO-LLM relevance score → webhook, drop the rest.** The pipeline shape, plus its honesty (publish each source's ToS status: clean/grey/blocked).
5. **Brandwatch/Meltwater — the archive + the explained spike.** Keep everything timestamped from day 1 (the archive is the only moat that compounds); ship spike detection *with an explanation* ("mentions of X up 4× because of Y thread"), not a bare alert. (Brand24's AI Insights weekly report is the cheap version of the same idea — copy the weekly cadence for the pilot brief.)

## Ranked: 5 biggest differentiation openings

1. **Ranked action brief, not an alerts feed.** Nobody under $599 ships "do this first, then this, here's the draft, here's the thread". Helios's deliverable is a Monday brief: top 5 problems / top 3 competitor moves / top 3 unmet needs, each with recommended action + draft reply + author-fit note. This is the wedge; everything else is table stakes.
2. **Dev-community focus as the product, not a source list.** GitHub Issues + HN + Stack Overflow/DEV + X + Bluesky, ranked for *founder-led B2B AI/dev-tool* buyers. Octolens is the only incumbent that even selects for this audience — and it charges $159 for a feed. Helios owns the niche by ranking *by problem type* (bug, missing feature, migration pain, pricing complaint, "looking for X") instead of by keyword.
3. **Transparent, auditable scoring.** Show *why* each item ranked where it did (intent tag + author fit + recency + evidence quote), per Lead Signal Listener's rule transparency. Every incumbent's score is a black box; Brand24's own users report sarcasm mislabelled as positive. Publish the accuracy log (hits *and* misses) — no incumbent does this honestly.
4. **Price + terms as a feature.** Month-to-month, no demo gate, no annual lock-in, no per-seat tax, no quote-only listening add-on, no X add-on, no speed-gating (same alert speed on every plan, cf. SnitchFeed). The incumbents' pricing *is* the pain: Mention $599 annual-only, Sprout per-seat + quote-only Listening, Brandwatch/Meltwater/Talkwalker quote-only. Helios's $57–170 founder band, published, is itself the pitch.
5. **Compliant-by-design sourcing, stated per source.** Publish a source table (HN: Algolia, free, no key; Bluesky: public AppView, free; GitHub: official API; RSS: free; X: official pay-per-use, bounded; LinkedIn: no cheap compliant path — say so; Reddit: RSS dead 13 Nov 2026, public API dead Mar 2027 — use Reddit Pro / licensed partner, or exclude Reddit and say why). No incumbent publishes this; the grey routes (OpenMagpie X session cookie, Lead Signal Listener Treg reseller) are exactly what kills tools (GummySearch, Proxycurl precedent). Helios's honesty here is a trust moat with technical buyers.

## What Helios should NOT copy (anti-patterns, verified)

- **Per-seat pricing** (Sprout) / **quote-only listening as an add-on** (Sprout, Mention/Agorapulse) / **annual-only $599** (Mention) / **demo-gated quote-only** (Brandwatch, Meltwater, Talkwalker).
- **Metering raw matches** (Octolens counts every match even if AI marks it irrelevant) — meter delivered/ranked items.
- **Speed-gating** (Brand24 12-hourly on Individual, real-time only on Pro $399) — same speed on every plan.
- **Borrowed-data moats** (BuzzSumo engagement data; GummySearch Reddit licence) — own the collection path or state the dependency.
- **GEO "training" claims** (MentionFox GEOFixer) — measure AI visibility, never claim to train LLMs.
- **Single-source dependence** (GummySearch/Reddit) — HN+Bluesky+GitHub+RSS are the durable free core; X is bounded and paid; Reddit is optional/licensed.
